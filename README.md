# F4TE — Portfólio (GitHub Pages)

Site estático, sem build, sem dependências externas. Pronto para o GitHub Pages.

- `index.html` — site completo (HTML + CSS + JS inline)
- `.nojekyll` — impede o Jekyll de processar os arquivos

## Publicar em 4 passos

1. Crie um repositório público chamado `F4te.github.io` (troque `F4te` pelo seu usuário do GitHub, exatamente igual).
2. Envie os arquivos `index.html` e `.nojekyll` para a branch `main`.
3. Em **Settings → Pages**, confirme em *Source*: **Deploy from a branch** → `main` → `/ (root)`.
4. Aguarde ~1 minuto e acesse `https://SEU-USUARIO.github.io`.

O passo a passo completo com comandos Git está na resposta do chat.
